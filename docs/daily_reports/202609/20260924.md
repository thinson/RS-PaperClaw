# 日报 20260924

## 📌 今日概况

今日共检索候选论文 13 篇；关键词+LLM 智能匹配遥感交叉论文 8 篇；最终纳入日报 8 篇。

今日论文聚焦遥感基础模型的可解释性与不确定性量化，涵盖连续处理因果推断、嵌入地理信息泄露及城市表征压缩问题。边缘计算与轻量化部署成为热点，涉及VLM推理优化、小目标检测蒸馏及有限监督下的DEM重建。高光谱领域出现被动测距与图半监督分类新方法，整体呈现从模型性能向可靠性、效率与隐私安全并重的趋势。

## ✨ 今日亮点

- 地理嵌入可恢复位置信息，引发基础模型隐私与安全担忧
- 边缘端VLM推理利用答案不变冗余实现token剪枝加速
- 连续处理因果推断引入图局部保形推理量化不确定性
